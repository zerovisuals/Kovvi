# Design references

Drop references here: screenshots, exports, video captures, moodboards, or a
plain text file of links. Annotated beats clean — a note saying *why* a
reference is here is worth more than the image itself.

Supply them as they exist rather than saving them all for the end. Each one
that arrives early shapes structure, instead of having to be retrofitted onto
structure that already hardened.

This folder is gitignored by default (references are often large, and sometimes
third-party material). Remove the `design-references/` line from `.gitignore`
if they should be versioned with the project.

See ../BRAND-INTAKE.md for the full handover sheet.
